# ☕ 쿠폰 적립 시스템 (Java 콘솔 기반 / MVC 아키텍처)

Java로 구현된 콘솔 기반 **쿠폰 적립 시스템**입니다.  
회원 등록부터 쿠폰 적립, 사용, 검색까지 기능을 포함하며,  
**MVC 패턴**을 적용하여 유지보수성과 확장성을 고려한 구조로 설계되었습니다.

---

## 📌 주요 기능

1. **회원 등록**
    - 이름과 전화번호(형식: `010-1234-5678`)를 입력받아 회원을 등록합니다.
    - 동일 전화번호는 중복 등록할 수 없습니다.
    - 전화번호 형식이 잘못되었을 경우 `IllegalArgumentException`을 발생시키고 프로그램을 종료합니다.

2. **쿠폰 검색**
    - 전화번호 뒷자리 4자리로 회원을 검색합니다.
    - 동일한 뒷자리 회원이 여러 명일 경우, 이름을 추가 입력받아 정확한 회원을 선택합니다.

3. **쿠폰 적립**
    - 전화번호 뒷자리 4자리로 회원을 검색 후 본인 여부를 확인합니다.
    - 적립할 쿠폰 개수를 입력받아 추가합니다.

4. **쿠폰 사용**
    - 전화번호 뒷자리 + 이름으로 회원을 식별하고, 사용할 쿠폰 개수를 차감합니다.
    - 보유 쿠폰보다 많은 수량을 사용할 경우 오류 메시지를 출력합니다.

5. **프로그램 종료**
    - 메뉴에서 5번 선택 시 종료됩니다.
